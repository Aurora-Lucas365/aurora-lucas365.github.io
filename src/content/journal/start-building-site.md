## 今天的成果

大约 3 个小时，在 AI 的帮助下做完了这些：

- 想清楚了网站的定位：不是成品展示，而是记录项目和学习的历程。
- 在 Obsidian 里搭好了发布体系：一条发布规则、两个模板，写好了 4 篇项目、1 篇历程和「关于我」的初稿。
- 在 GitHub 上建了网站仓库 aurora-lucas365.github.io，网址已经能打开，目前只显示一行介绍。
- 有了同步脚本和「发布网站」命令：在 Obsidian 里按 Ctrl+P，就能把勾了 publish 的笔记推到 GitHub。

还没做的：用 Astro 把笔记变成真正的网页，以及视觉设计和交互。

## 这段时间做了什么

1. **提需求**：想做一个放项目的个人网站，参考 Obsidian 笔记，要能交互。AI 先做了一版网页雏形。
2. **发现方向不对**：我的项目还在打磨，网站应该用来记录过程；我想要的交互是苹果官网那种滚动动画。于是重新定了方向。
3. **弄清托管**：静态网站不需要服务器。比较了 GitHub Pages 和 EdgeOne Pages，决定先用免费的 GitHub Pages。
4. **整理 Obsidian**：定规则、建文件夹和模板、改设置，把项目笔记改成能公开的版本（去掉本机路径和网盘链接，标明复刻和竞赛内容）。
5. **建仓库**：在 GitHub 新建仓库，用 git clone 下载到电脑。
6. **打通发布**：放入同步脚本和一键发布文件，装 Shell commands 插件，第一次推送成功。

## 卡在哪里

- **概念混在一起**：备案、域名、境外节点、GitHub 和 GitHub Pages 一开始分不清。
- **Obsidian 不熟**：属性、模板、附件位置都是第一次配。
- **误以为建仓库失败**：页面提示「Repository creation failed」，其实仓库已经建好了，多半是按钮点了两次，第二次因为重名才报错。
- **插件设置页是空的**：Shell commands 找不到新建按钮，最后由 AI 直接写进插件的配置文件解决。
- **误以为推送出错**：推送时出现「LF will be replaced by CRLF」的提示，其实只是 Windows 和 Linux 的换行符不同，可以忽略。
- **自己还做不下来**：网站相关的代码基本是 AI 写的。

## 学到了什么

**几个概念**

- **静态网站**：只有页面文件，没有后台和数据库，不需要自己的服务器，用免费托管就行。
- **备案**：针对放在中国大陆服务器上的网站，不是买了域名就要备案。
- **GitHub Pages**：GitHub 的免费网页托管。仓库名写成「用户名.github.io」会自动开通，网址就是仓库名。
- **git 的三个动作**：clone 把仓库下载到电脑；commit 把改动存成一个版本；push 把版本传到 GitHub。
- **笔记属性**：笔记开头的结构化信息。网站靠它知道标题、日期、放在哪个栏目。

**几条经验**

1. 先想清楚给谁看、放什么，再动手。一开始直接让 AI 做网站，做出来好看，但不是我要的。
2. 公开前先想隐私。只发布手动勾选的笔记；本机路径、网盘链接、私人笔记、评奖前的比赛论文都不放。
3. 内容要诚实。复刻的项目写明原作者，竞赛作品说明用的是常规方法，不确定的先写「待补充」，不要编。
4. 每一步都验证。先在没有勾选任何笔记的情况下跑一次发布，确认流程通了，再放真正的内容。
5. 看到报错先别慌。先读报错内容、查一下实际状态，很多「错误」只是提示。
6. 一条路走不通就换一条。插件界面出问题，就绕过界面直接改配置。
7. 让 AI 做重复和技术细节，自己负责决定和检查。哪些内容公开、项目怎么描述，只能自己定。

## 为什么还是觉得自己做不下来

今天的分工大概是这样：

- **我做的**：定方向和内容取舍，补充事实，注册和建仓库，运行命令，装插件，检查结果。
- **AI 做的**：解释概念，写同步脚本，改配置，起草笔记。

做不下来，主要不是动手能力的问题，而是缺两样东西：一是概念不熟，不知道下一步该做什么；二是不会写网站代码。第一样今天已经补了不少。第二样不需要一下子学会，目标是每一步都知道「为什么这么做、做完怎么检查」。代码可以让 AI 写，但要看得懂它在干什么。

## 接下来

- 搭网站时，先按说明自己敲命令，卡住了再问；每个命令的作用记到笔记里。
- 用 Astro 搭骨架，把笔记变成网页，再切换到 GitHub Actions 自动构建。预计 2–3 小时，可以分 3 次做。
- 网站能用以后，再做视觉设计和滚动交互。

## 给想做同样事情的人

想用 Obsidian 写笔记、自动发布成个人网站，可以按这个顺序：

1. 想清楚网站给谁看、放什么。
2. 在 Obsidian 里定一条发布规则（比如属性 publish 打勾才公开），做好模板。
3. 在 GitHub 建一个「用户名.github.io」仓库。
4. 用同步脚本把勾选的笔记搬进仓库，再推送。
5. 用 Astro 这类工具把笔记生成网页，交给 GitHub Pages 自动发布。

全程免费，不需要服务器，也不需要备案。
